# 以撒控制台助手

适配 **The Binding of Isaac: Repentance v1.7.9b.J835** 的 Windows 离线命令速查工具。v1.1.0 默认开启中文模糊搜索，也支持英文、拼音、别名与 ID；填写参数后复制命令，并提供收藏、最近复制和窗口置顶。

## 打开软件

完整解压发布 ZIP，双击 **IsaacConsoleAssistant.exe**。请保留同目录的 resources、locales、DLL 等配套文件，不要仅复制 EXE，不要直接在压缩包中运行。不需要安装 Node.js、Python 或额外 Mod。

## 使用

1. 直接输入想做的事，如“获得两个金币”“开启飞行”“重开本关”，也可输入“神秘礼物”“smlw”“c515”。模糊搜索默认开启，无需设置；按 Ctrl + K 快速定位搜索框。
2. 点击结果，在右侧选择操作和参数，检查命令预览。
3. 点击“复制命令”，或按 Ctrl + Enter。
4. 游戏中进入一局，切换英文键盘，按 ~ 打开调试控制台，Ctrl + V 粘贴并回车。

例如，搜索“神秘礼物”并获取可复制 `giveitem c515`；搜索“增加金币”，输入 7，可复制 `lua Isaac.GetPlayer(0):AddCoins(7)`。

中文模糊搜索会把匹配到的操作和数量自动填入右侧，并展示“已理解你的输入”。例如：

| 输入 | 匹配与参数 |
| --- | --- |
| 获得两个金币／给我两枚硬币 | 增加金币，数量 2 |
| 增加十二把钥匙 | 增加钥匙，数量 12 |
| 恢复一颗半红心 | 恢复红心，数量 3 个半心单位 |
| 开启飞行 | 获取超凡升天 `giveitem c20`，会添加此道具 |
| 关闭飞行 | 移除超凡升天；其他道具提供的飞行仍可能保留 |
| 重开本关／重置本层 | 动态读取当前楼层和分支，重置当前整个楼层；同时提供房间回溯和重新开局候选 |
| 重开当前房间 | 房间回溯 `rewind`，具体回退位置由游戏房间历史决定 |
| 重开 | 以当前角色重新开局 `restart` |
| 获得神秘礼物／移除硫磺火 | 对应道具的获取／移除操作 |

支持阿拉伯数字、中文数字与有限的名称错字容错。数量越界或不符合参数类型时会显示错误并禁用复制，不会偷偷截断或限制到另一个数值。口语查询在当前分类找不到时会尝试跨分类意图匹配，并标注提示；收藏和历史保持各自筛选范围。

这是本地规则与名称近似匹配，不是联网 AI，不能理解任意中文句子。一条结果只生成一条命令；请核对匹配结果和影响后再复制。无敌等原生 debug 命令是切换状态，软件不把“开启／关闭”说成已读取游戏状态。

如需自行开启控制台，请先关闭游戏并备份 `Documents\My Games\Binding of Isaac Repentance\options.ini`，再把 `EnableDebugConsole` 改为 `1`。本工具不会自动修改配置、存档，也不会向游戏发送命令或安装 Mod。

收藏按钮位于详情右上方；“最近复制”保存最近 100 次成功复制，可以按原参数再次复制、删除单条或清空。置顶按钮位于窗口右上方。胶囊效果 ID 可以为 0；胶囊效果与地面胶囊颜色 ID 不同，因此胶囊效果目录仅提供获取操作。

## 目录范围与核对

物品 ID 均与本机 `resources/scripts/enums.lua` 逐项比对：721 个收藏品、189 个饰品、97 个卡牌／符文、50 个胶囊效果、41 个角色形态、46 个挑战编号（含 0 无挑战）、43 个普通模式楼层组合，以及 779 条实体类型与公开变体。另含原生控制台命令和资源 Lua 模板。道具枚举存在保留空号，不能按 1–732 每个数字都可用来理解。

实体目录包含可检索的实体类型、掉落物和公开的跟班／特效／炸弹变体，**不包含未公开的全部敌人变体**；部分实体保留英文名称。部分内部实体生成需要正确的变体、拥有者或房间环境。参数合法不保证所有实体组合都可独立生成。楼层目录用于普通模式，贪婪模式编号不同。房间传送编号与当前楼层有关。软件中没有把 Mod 专属命令或 Repentance+ 物品当作原版能力收录。

复制成功表示文本已写入系统剪贴板。游戏内命令效果需在游戏中确认，项目的自动化验证不会启动对局或执行命令。

## 本地记录

默认记录目录为 `%APPDATA%\isaac-console-assistant\state-v1.json`，存储收藏、最近复制和置顶设置。损坏文件会先备份为 `state-v1.json.corrupt-时间戳`，然后恢复默认值。关闭软件后可自行备份该目录。历史复制只保存命令文本，不读取游戏存档。

## 源码开发（Git Bash）

需要 Node.js 22.12+（本机使用 Node.js 24）和 npm。执行：

```bash
npm ci
npm run build
npm start
```

修改界面：`src/main.ts`、`src/style.css`、`src/theme.css`。修改命令模板和验证：`src/core.ts`。修改目录：`src/data/catalog.json`。主进程和 preload 在 `electron/`。`npm run dev` 仅预览界面，剪贴板、记录和置顶需要使用桌面窗口。

```bash
npm test
npm run test:desktop
npm run package
```

桌面测试写独立测试目录，不会覆盖真实使用记录；会短暂占用系统剪贴板。构建发布包位于 `release/`。

若需按本机游戏重新整理数据，需安装 Python 3.10+ 并运行：

```bash
python scripts/build_catalog.py --game 'E:/你的游戏目录'
```

此步骤只读游戏文件，首次联网下载固定版本的 MIT 物品速查资料到 `.cache/sources/`。普通安装、运行、测试、打包均使用已附带的离线目录，不依赖游戏安装路径或外部服务。

第三方来源、数据版本与许可见 `THIRD-PARTY-NOTICES.md`；验证结果见 `验证报告.md`。
