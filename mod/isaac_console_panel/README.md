# 以撒游戏内指令面板 v0.1.0 试用版

适配基准：本机 Repentance v1.7.9b.J835。独立 Lua Mod，不需要 EID、桥接程序或联网。桌面软件继续保留。

本版依赖匹配 J835 的 **REPENTOGON 1.0.12e**，以原生暂停菜单状态暂停战斗与计时。关闭面板并松开按键后恢复；Esc 返回；B 逐层返回，在最外层再次按下关闭，松开按键后恢复战斗。组件缺失时会提示并拒绝打开。用户已确认旧版指令执行有效；本次暂停集成仅完成离线检查，实际效果待重新进入游戏验收。组件来源和回退见 `暂停组件说明.md`。

## 安装与移除

将 ZIP 内的 `isaac_console_panel` 整个文件夹放入游戏 `mods` 目录，不能再嵌套一层。保留此文件夹名称，字体使用固定路径加载。重新启动游戏，在 Mods 菜单启用本 Mod，进入单人对局后按 F8，或按下手柄十字键上。

本机安装路径：`E:\The.Binding.of.Isaac.and.The.Binding.of.Isaac.Rebirth.Build.10102354\mods\isaac_console_panel`。

游戏运行时不要覆盖 Mod 文件。停用：在游戏 Mods 菜单关闭本 Mod 并重启。移除：退出游戏后删除独立的 `mods/isaac_console_panel` 文件夹。通过游戏 Mod 保存接口写出的本 Mod 记录可能由游戏保留；删除程序不会主动清除它们。本 Mod 不读写原游戏存档、不改游戏设置、不修改其他 Mod。

## 操作

| 操作 | 键盘 | 手柄 |
|---|---|---|
| 打开 / 关闭 | F8（可配置为 F9、F11） | 十字键上按下立即打开；B 退到最外层再按关闭；也可选“关闭”后 A |
| 切换区域 | F1，或 ← / → 在分类、结果、参数之间移动 | 方向 ← / →，或菜单左右切换映射 |
| 分类 | 分类区 ↑ / ↓；PageUp / PageDown 为快捷方式 | 分类区十字键／左摇杆 ↑ / ↓，→ 进入结果；首项上移到搜索栏 |
| 搜索 | 直接输入英文、拼音、首字母、ID | 结果首项向上选中搜索栏，A 打开字符面板；方向选字、A 输入、B 完成 |
| 选结果 / 翻页 | 结果区 ↑ / ↓，到页边缘自动翻页 | 结果区左摇杆 ↑ / ↓ |
| 数量 | → 进入参数区，数量处 ← / → 调整 | 参数区数量处方向 ← / →；A 加 1 |
| 切换获取 / 移除、开启 / 关闭 | 参数区 ↑ / ↓ 选“操作”后 Enter；或 F2 | 参数区选“操作”后 A |
| 执行 | 结果区 Enter，或参数区选“确认执行”后 Enter | 结果区 A，或参数区选“确认执行”后 A |
| 返回 | Esc，逐层返回，主列表也不关闭面板 | B，逐层返回，最外层再按关闭 |
| 收藏 | 参数区选“收藏”后 Enter；或 F3 | 参数区选“收藏”后 A |
| 清搜索 | 参数区选“清空”后 Enter；或 Ctrl+K / Backspace | 参数区选“清空”后 A |
| 删除 / 清空历史 | 历史分类内，参数区选对应控件后 Enter；Delete 删除单条 | 历史分类内，参数区选“删此条” / “清历史”后 A；清空需两次确认 |
| 配置热键 | 参数区选“改键”后 Enter | 参数区选“改键”后 A |

金色边框表示当前焦点。参数区用 ↑ / ↓ 依次选择数量、操作、收藏、执行、历史管理、清空、搜索、改键和关闭；只有历史分类显示历史管理控件。Esc / B 的返回顺序：关闭字符输入、取消待确认动作、从参数回结果、清空搜索、返回全部分类；主列表中 B 再按关闭，Esc 仍不关闭。鼠标仅为辅助，使用世界坐标转屏幕坐标定位，提供悬停反馈和面板指针。

键盘搜索请切换到英文输入法，直接输入 `feixing` 或 `jinbi2`，搜索栏应立即显示字母。面板打开及关闭后的释放等待期间会拦截原生全屏、静音等动作，避免输入 F / M 时触发游戏快捷键；面板关闭并松开按键后恢复原绑定。键盘直接读取物理键，不再同时使用空格、Q、E 的原生菜单映射；手柄菜单操作从手柄索引读取。兼容本机 EID 的键盘输入包装，并排除手柄按键被误判为 Ctrl 等键盘键的情况。

关闭后会等待键盘、手柄和鼠标按键释放，再恢复游戏输入。若暂时不能移动，先松开所有按键、摇杆与扳机。原生暂停菜单、Mod Config Menu 或本机 GoodTrip 的 `gt.mapHeld` 为真时不显示面板；其他菜单中途接管时面板自动关闭。未暴露打开状态的其他 Mod 菜单无法统一识别，需实际兼容性测试。为避开 GoodTrip，分类使用 PageUp / PageDown；未修改 GoodTrip 的 Tab、手柄映射或 MCM 的 F10。

## 检索与动作

- `shengxin` 或 `sx`：圣心；首字母可能同时匹配多个名称，用上下键选择。
- `c515`：道具 515；`t1`：饰品 1；`k1`：卡牌 1；`p0`：胶囊效果 0。直接数字也可查询，类型分别列出。
- `jinbi2`：数量自动填入 2；`jinbi-2`：减 2 金币。数量越界会提示，执行前不会自动篡改输入数值。
- `feixing`、`wudi`：本 Mod 管理的飞行、无敌开关；再次进入详情时默认选相反操作。飞行关闭后重新计算角色与道具的自然飞行。无敌只拦截玩家受伤，不保证阻止强制结束对局等机制。
- `chongkai`：重新开局；`chongkaibenguan`：重置当前楼层；`huifangjian`：回溯房间，三者分别列出。重置楼层、重新开局以及楼层传送都需二次确认，确认后关闭面板。回溯结果取决于游戏保存的房间历史。
- 红心、魂心、黑心和心之容器：数量以半颗 / 半个计，2 表示完整一颗 / 一个。其他资源按整数计。资源有角色与容量限制；黑心、骨心等部分资源首版只提供增加。
- 收藏与最近 100 条成功执行历史持久保存。历史再次执行时重新验证条件；清空历史需要二次确认。能力状态仅保存在当前局标识下，继续同局恢复，新局清除。

完整目录含 721 道具、188 饰品、97 卡牌 / 符文、50 胶囊效果，另有 11 资源、2 能力、3 房间 / 重开动作及 50 楼层项（43 普通、7 贪婪）。筛选当前游戏模式的楼层，枚举保留空号、过时饰品 47 不生成可执行项。

只允许单玩家执行；检测到多个玩家实体（包括部分双角色形态）将禁用动作。获取卡牌 / 胶囊可能置换口袋物品，获取主动道具可能替换主动栏；满饰品栏会拒绝添加。模组只执行白名单动作，不接收任意 Lua。指定胶囊效果、回溯和楼层切换使用原生命令，其余优先使用玩家 API。

首版不支持中文输入法整句、通用语义理解、实体生成、自定义 Lua、Repentance+。使用过 Mod 的对局由游戏自己的规则决定成就状态，软件不更改相关条件。

## 源码与构建

源码位于仓库 `mod/isaac_console_panel`。`main.lua` 注册回调；`icp/search.lua` 检索；`panel.lua` 管理选择和确认；`render.lua` 渲染；`actions.lua` 执行白名单动作；`state.lua` 清理及保存状态；`catalog.lua` 自动生成；`pause.lua` 管理原生暂停的取得与释放。

在仓库根目录执行（Git Bash，Python 3.10+、Node.js 22.12+）：

```bash
npm ci
python -m pip install --target .cache/python lupa==2.8 Pillow fonttools
npm run mod:package
```

已有生成字体随源码提供；重新生成字体首次需联网下载 Noto Sans SC，之后使用缓存。数据生成读取现有桌面目录，不执行游戏脚本。输出 `release/以撒游戏内指令面板-0.1.0.zip`。离线测试分别使用 Lua 5.3 和 5.4 模拟 API，不向游戏发送任何命令。字体、数据来源与许可见 `来源与许可.md`、`licenses/` 和 `catalog-sources.json`。

## 手柄开关（2026-10-20 更新）

按手柄十字键上立即打开；面板打开后，上键只导航，不关闭。B 逐层返回，退至全部分类、无搜索内容的主列表后再按关闭；长按 B 不连续跨层。LB＋RB 组合键已取消，双肩键不再触发面板。键盘 F8（可改为 F9/F11）保留。

十字键上已由本 Mod 用作面板开关，在正常游戏中不再用于向上移动；向上移动使用左摇杆；面板打开后十字键上与左摇杆均可向上导航。键盘 ↑ 保持原用途，面板内 LB/RB 单按仍可切区。炸弹、主动道具、卡牌和 RT 丢弃的原版输入不做延迟、重放或改绑。

其他菜单打开时该热键不叠加面板；退出菜单后先松开十字键上再按。关闭后等待按键释放再恢复战斗；Esc 仍只返回；B 返回最外层后再按关闭。原版按键配置文件保持不变，拦截由 Mod 在运行期间完成。

## MCM 配置菜单

进入单人对局，在安全房间按 **F10** 或 **R3** 打开 Mod Config Menu，选择 **以撒指令面板 → 按键设置**。

| 配置项 | 默认值 | 可选值 |
|---|---|---|
| 键盘开关键 | F8 | F8 / F9 / F11 |
| 启用手柄打开键 | 开启 | 开启 / 关闭 |
| 手柄打开键 | 十字键上 | 上 / 下 / 左 / 右 |

修改后立即写入本 Mod 的保存数据，重启后保留；面板内“改键”与 MCM 键盘项同步。选中某项后按 MCM 的 R 可恢复该项默认值，不清除收藏、历史或能力状态。新字段会给旧存档补默认值，不重置用户记录。

关闭手柄开关后，十字键恢复原用途，手柄在面板内的导航仍能使用，键盘开关也保留。选中的手柄方向在正常游戏中专门用于打开面板；面板中十字键和左摇杆均可导航，关闭菜单后先松开新开关键再按。当前设置会在面板底部提示。

MCM 为可选依赖，未安装时仍可正常使用面板；兼容 MCM 晚于本 Mod 加载，不改 MCM 自身配置或其他 Mod 的配置页。本轮只增加配置入口，不修改暂停机制或恢复 LB＋RB 组合键。

## 搜索栏的方向导航

在结果列表第一项按上进入搜索栏；分类第一项或参数第一项按上也可以进入。搜索栏有金色焦点边框，按 A / Enter 打开字符输入，按下回到刚才的列表区域。无搜索结果时也能用上／下进入搜索栏。F1 切区包含搜索栏；原参数区“搜索”入口保留。

B 依次退出字符输入、取消二次确认、返回结果、清空搜索、返回全部分类，最后一次关闭。搜索栏焦点下按 B 先返回原列表。关闭后继续等待按键释放再恢复游戏；F8 仍能直接关闭。
