# 以撒游戏内指令面板 v0.1.0 试用版

适配基准：本机 Repentance v1.7.9b.J835。独立 Lua Mod，不需要 EID、桥接程序或联网。桌面软件继续保留。

**面板不会暂停整个游戏，角色仍可能受到伤害。请先在安全房间试用。** 打开时会拦截角色输入，怪物、弹幕与房间计时仍继续运行。此版本的离线测试通过；游戏内效果、中文显示及其他 Mod 兼容性待用户按《游戏内测试清单》确认。

## 安装与移除

将 ZIP 内的 `isaac_console_panel` 整个文件夹放入游戏 `mods` 目录，不能再嵌套一层。保留此文件夹名称，字体使用固定路径加载。重新启动游戏，在 Mods 菜单启用本 Mod，进入单人对局后按 F8。

本机安装路径：`E:\The.Binding.of.Isaac.and.The.Binding.of.Isaac.Rebirth.Build.10102354\mods\isaac_console_panel`。

游戏运行时不要覆盖 Mod 文件。停用：在游戏 Mods 菜单关闭本 Mod 并重启。移除：退出游戏后删除独立的 `mods/isaac_console_panel` 文件夹。通过游戏 Mod 保存接口写出的本 Mod 记录可能由游戏保留；删除程序不会主动清除它们。本 Mod 不读写原游戏存档、不改游戏设置、不修改其他 Mod。

## 检索与动作

- `shengxin` 或 `sx`：圣心；首字母可能同时匹配多个名称，用上下键选择。
- `c515`：道具 515；`t1`：饰品 1；`k1`：卡牌 1；`p0`：胶囊效果 0。直接数字也可查询，类型分别列出。
- `jinbi2`：数量自动填入 2；`jinbi-2`：减 2 金币。数量越界会提示，执行前不会自动篡改输入数值。
- `feixing`、`wudi`：本 Mod 管理的飞行、无敌开关；再次进入详情时默认选相反操作。飞行关闭后重新计算角色与道具的自然飞行。无敌只拦截玩家受伤，不保证阻止强制结束对局等机制。
- `chongkai`：重新开局；`chongkaibenguan`：重置当前楼层；`huifangjian`：回溯房间，三者分别列出。重置楼层、重新开局以及楼层传送都需二次确认，确认后关闭面板。回溯结果取决于游戏保存的房间历史。
- 红心、魂心、黑心和心之容器：数量以半颗 / 半个计，2 表示完整一颗 / 一个。其他资源按整数计。资源有角色与容量限制；黑心、骨心等部分资源首版只提供增加。
- 收藏与最近 100 条成功执行历史持久保存。历史再次执行时重新验证条件；清空历史需要再次点击确认。能力状态仅保存在当前局标识下，继续同局恢复，新局清除。

完整目录含 721 道具、188 饰品、97 卡牌 / 符文、50 胶囊效果，另有 11 资源、2 能力、3 房间 / 重开动作及 50 楼层项（43 普通、7 贪婪）。筛选当前游戏模式的楼层，枚举保留空号、过时饰品 47 不生成可执行项。

只允许单玩家执行；检测到多个玩家实体（包括部分双角色形态）将禁用动作。获取卡牌 / 胶囊可能置换口袋物品，获取主动道具可能替换主动栏；满饰品栏会拒绝添加。模组只执行白名单动作，不接收任意 Lua。指定胶囊效果、回溯和楼层切换使用原生命令，其余优先使用玩家 API。

首版不支持中文输入法整句、通用语义理解、实体生成、自定义 Lua、全局手柄组合键、Repentance+。使用过 Mod 的对局由游戏自己的规则决定成就状态，软件不更改相关条件。

## 源码与构建

源码位于仓库 `mod/isaac_console_panel`。`main.lua` 注册回调；`icp/search.lua` 检索；`panel.lua` 管理选择和确认；`render.lua` 渲染；`actions.lua` 执行白名单动作；`state.lua` 清理及保存状态；`catalog.lua` 自动生成。

在仓库根目录执行（Git Bash，Python 3.10+、Node.js 22.12+）：

```bash
npm ci
python -m pip install --target .cache/python lupa==2.8 Pillow fonttools
npm run mod:package
```

已有生成字体随源码提供；重新生成字体首次需联网下载 Noto Sans SC，之后使用缓存。数据生成读取现有桌面目录，不执行游戏脚本。输出 `release/以撒游戏内指令面板-0.1.0.zip`。离线测试使用 Lua 5.3 模拟 API，不向游戏发送任何命令。字体、数据来源与许可见 `来源与许可.md`、`licenses/` 和 `catalog-sources.json`。
