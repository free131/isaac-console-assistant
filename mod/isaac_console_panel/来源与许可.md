# 来源与许可

本 Mod 独立开发，与游戏发行方和参考项目无隶属关系。不附带游戏程序或游戏图像。

- 数据从本仓库桌面目录生成，基准为本机 Repentance v1.7.9b.J835 的 `resources/scripts/enums.lua`。校验摘要与目录数量见 `catalog-sources.json`。排除保留对象、过时饰品以及 Repentance+ / Mod 专属数据，不擅自补齐 ID 空号。
- 中文 / 英文名称和物品短描述参考 [roiiiu/isaac-cheat-sheet](https://github.com/roiiiu/isaac-cheat-sheet/tree/7d59952d4e5718ac80ebf9a60b4f7c5611557952)，固定提交见链接；MIT 版权和许可全文保存在 `licenses/isaac-cheat-sheet-MIT.txt`。
- 少量名称使用本机 [External Item Descriptions](https://github.com/wofsauge/External-Item-Descriptions) 的 `descriptions/names/zh_cn.lua` 名称字符串核对，不分发 EID 脚本、字体或整段机制说明。
- API 行为参考 [IsaacDocs](https://github.com/wofsauge/IsaacDocs)，特别是 Font、EntityPlayer、Input、CacheFlag 与 DebugConsole 文档；未复制其实现代码。文档中的 Repentance+ 专有接口未采用。
- 字体由 [Google Fonts 的 Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) 生成 BMFont v3 位图子集，原始字体摘要、字形列表保存在 `resources/font/manifest.json`。派生字体名 ICP Panel，OFL 1.1 全文附在 `licenses/NotoSansSC-OFL.txt`；原字体版权归其作者所有。
- 构建期拼音生成使用 pinyin-pro（MIT），运行时不依赖该库。Lua 5.3 离线测试使用 lupa；字体构建使用 Pillow 与 fontTools，均为开发工具，不打包进 Mod。

本版本只有离线验证记录；实际游戏效果以用户测试为准。
